LégiCite

Citer et consulter les articles de loi français depuis Word, via l'API Légifrance.

Citer

Dans le document, tapez /art 111-1 cpen puis Entrée. L'article est inséré in extenso, composé selon vos réglages.

  • /art 111-1, 111-2 et 111-3 cpen — une liste
  • /art 111-1 à 111-5 cpen — une plage, résolue par le sommaire du code
  • /artv 1353 cciv 2020 — la version en vigueur à une date
  • /citart — l'article annoncé par la phrase qui précède

Consulter

Sélectionnez une référence dans le texte, clic droit, Consulter dans LégiCite : l'article s'affiche dans le volet, sans quitter le document.

Aide

L'installation, les réglages et le dépannage sont décrits dans le README du dépôt. Un compte PISTE abonné à l'API Légifrance est nécessaire ; l'accès est gratuit après inscription.

Les données proviennent de Légifrance et sont diffusées sous Licence Ouverte 2.0 : réutilisation libre, sous réserve de mentionner la source et la date d'extraction.
